Installation

How to install the patch

Use a legally obtained Japanese Steam copy of BLACK SHEEP TOWN, Python 3.10 or newer, and about 300 MB of free space while the game data is rebuilt.

  1. 01

    Download and extract the patch

    Download BLACK_SHEEP_TOWN_English_v1.3.0.zip (7.1 MB) ↓

  2. 02

    Run the installer for your system

    Updating an older patch? Restore Japanese with the previous package first. On Windows, double-click Install BLACK SHEEP TOWN English Patch.bat. On macOS, double-click Install BLACK SHEEP TOWN English Patch.command.

  3. 03

    Choose the Japanese game folder

    Drag the BLACK SHEEP TOWN folder into the installer window, press Enter or Return, and wait for the verified-success message. The installer verifies Steam Build 13300478 before changing any files.

  4. 04

    Launch normally

    On Windows, run Bst.exe. On macOS or Linux, launch the same executable through Wine. Verification and Japanese-restoration helpers are included beside the installer.
