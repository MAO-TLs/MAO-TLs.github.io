Install v1.1.0

Use a legally obtained supported Japanese Windows copy of BLACK SHEEP TOWN, Python 3.10 or newer, and about 2.1 GB of free space while the game data is rebuilt.

  1. 01

    Download and extract the patch

    Download BLACK_SHEEP_TOWN_English_v1.1.0.zip (86.7 MB) ↓

  2. 02

    Run the installer for your system

    On Windows, double-click Install BLACK SHEEP TOWN English Patch.bat. On macOS, double-click Install BLACK SHEEP TOWN English Patch.command.

  3. 03

    Choose the Japanese game folder

    Drag the BLACK SHEEP TOWN folder into the installer window, press Enter or Return, and wait for the verified-success message. The installer automatically detects Steam Build 13300478 or the original Japanese Windows retail release.

  4. 04

    Launch normally

    On Windows, run Bst.exe. On macOS or Linux, launch the same executable through Wine. Verification and Japanese-restoration helpers are included beside the installer.
