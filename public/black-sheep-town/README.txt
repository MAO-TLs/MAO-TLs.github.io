BLACK SHEEP TOWN v1.0.0 — MAO release and script site

Open index.html for the release and installation page. Open script.html for the
bilingual browser. The script loads immediately when that page opens.

The publication shell and reader presentation are copied byte-for-byte from the
canonical MAO WHITE ALBUM 2 / Tsukihime templates, then reskinned with a strictly
grayscale title layer. Speaker names and confidence labels are research
metadata. They are never inserted into the game script.

The release page is built with placeholders for the verified patch archive.
finalize_release_site.py binds the public download URL, archive size, and SHA-256
only after validating the release receipt and installer verification record.
